GHCR image by digest. The VM had 1 CPU, 2 GiB RAM, and 10 GiB disk capacity.

## Results

- Full image download succeeded without registry credentials.
- exe.dev installed Shelley `0.1387.945564176` at VM creation.
- The VM owner confirmed that the Shelley button was visible in the dashboard.
- Shelley socket, browser mount, D-Bus, and user service manager were active.
  No systemd units were reported as failed before or after restart.
- The local Shelley API returned 403 without the identity header and 200 with it.
- Standalone browser tests passed JavaScript, typing, clicking, Canvas, WebGL
  pixels, PNG screenshots, and HTTPS navigation.
- Shelley used its own browser tools to open example.com, verify its title,
  fill and submit a test form, verify the result, and capture a screenshot.
- Git tests passed commit, branch, merge, rebase, clone, push, worktree, submodule,
  archive, PCRE search, garbage collection, integrity, and public HTTPS access.
- After a platform restart, the boot ID changed. A test file and the Shelley
  conversation remained readable. The browser RAM cache was empty, including
  after version and conversation queries. A subsequent browser test passed.

## Disk and memory observations

These are `df -B1 /` observations, including the platform-installed Shelley:

| Checkpoint | Used bytes | Used MiB |
| --- | ---: | ---: |
| Fresh VM, before browser use | 346992640 | 330.92 |
| After browser, Git, and Shelley integration tests | 348225536 | 332.09 |
| After restart and persistence checks | 355868672 | 339.38 |

The browser executable cache occupied 237152 KiB (about 232 MiB) in RAM after
use. Available memory was about 1.5 GiB after Shelley browser actions, and
about 1.8 GiB after restart with an empty cache. These are snapshots, not peak
memory guarantees. Browser processes require additional memory.

Chromium reported `156.0.8078.12`; Git reported `2.47.3`. New image builds and
platform-installed Shelley versions can change these measurements. User data,
installed tools, profiles, and logs increase persistent disk use.

## Limits

Only Linux AMD64 and the resource configuration above were tested on exe.dev.
The browser cache has a 320 MiB ceiling. Minimal Git omits scripting extras and
translations; the full Debian package can replace it through apt. Browser and
custom Git updates require a new image build; existing VMs are not updated by
publishing an image. See the README for details.
